# Languages and voice

English, Hindi, Malayalam, Tamil, and Telugu bundles are included and covered by the missing-key test. Non-English translations are machine-drafted and require native-speaker and clinical review; the UI discloses this during demo use. Fonts are self-hosted through `@fontsource`.

The browser Web Speech API is optional and may stream audio to the browser vendor. It is not an offline engine. Voice availability for `en-IN`, `hi-IN`, `ml-IN`, `ta-IN`, and `te-IN` is **NOT TESTED** in this checkout; no language is represented as clinically accurate or offline-capable.
